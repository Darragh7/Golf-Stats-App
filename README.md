# Golf Stats App

A web-based application built using Flask to help golfers track performance and analyse their game over time.

## Overview
This project was developed as part of a university web development module. It allows users to input and track golf round data, with a focus on improving decision-making and performance insights.

## Features
- Record golf rounds and scores
- Store and manage player data using a local database
- Simple interface for tracking performance over time
- Backend built with Flask and SQLite

## Tech Stack
- Python (Flask)
- SQLite
- HTML/CSS (Flask templates)

## Project Structure
- `app.py` – main application logic
- `database.py` – database interactions
- `forms.py` – form handling
- `schema.sql` – database schema
